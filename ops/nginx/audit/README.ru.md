# Проверка сайтов перед расширением deploy health check

Скрипт выполняет только GET / по HTTPS, не управляет сервисами и не требует root. Запускайте вне deploy. Включены ci.belov.email и семь имён сертификатов из предыдущего nginx -t; это не полный список server_name и не проверка всех SAN. Можно указать дополнительные/другие домены позиционными аргументами.

```sh
python3 ops/nginx/audit/check-sites.py --output /tmp/nginx-sites-audit-1.json
```

PASS: TLS успешно проверен, получен HTTP 2xx/3xx (для ci.belov.email только 200). Это доступность HTTPS, не доказательство правильного содержимого или конкретного vhost. REVIEW: получен другой HTTP-статус с успешным TLS; 401/403/404 могут быть ожидаемыми и требуют интерпретации. FAIL: ошибка подключения/TLS/протокола. Redirect не прослеживается, чтобы запрос не уходил на другой сервер.

Проверяются IPv4 93.115.20.205 и IPv6 2a0c:b9c0:f:433c::1 через --resolve, сохраняя SNI/имя для проверки сертификата. HTTPS/TCP принудительно использует HTTP/1.1; HTTP/2 отдельно не проверяется. Порты 80 и 7777 не проверяются, пока не определены ожидаемые ответы на них.

HTTP/3 проверяется только при наличии HTTP3 в curl --version и --http3-only в curl --help all. Fallback на TCP запрещён. Если нужной поддержки нет, выводится SKIP, это не результат проверки сервера. Можно выбрать уже установленный другой curl через --curl /path/to/curl; установка пакетов и скачивание образов не выполняются.

Запуск на VPS проверяет локальную доступность его публичных адресов, но не внешний маршрут/firewall. Повторите этот же скрипт на внешней машине с доступным IPv6, чтобы проверить доступ из интернета. FAIL IPv6 на машине без IPv6 не доказывает неисправность сервера.

До разбора результатов не добавляйте этот обзорный скрипт в обязательный deploy gate: закрытые или не настроенные корни доменов могут возвращать не-200 штатно. Итоговый exit 1 означает наличие FAIL/REVIEW, 2 — ошибку самого аудита. HTTP3=SKIPPED не меняет код выхода. JSON содержит статусы и ошибки, без тел ответов и секретов; существующий отчёт не перезаписывается.
